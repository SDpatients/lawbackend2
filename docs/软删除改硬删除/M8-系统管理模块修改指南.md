### 步骤2：修改 Service

#### 2.1 UserServiceImpl

**文件**: `service/impl/UserServiceImpl.java`

**级联删除用户及其关联**:

```java
// 修改前
@Transactional
public void deleteUser(Long id) {
    User user = userRepository.findById(id)
        .orElseThrow(() -> new BusinessException("用户不存在"));
    user.setIsDeleted(true);
    userRepository.save(user);
}

// 修改后
@Autowired
private UserRoleRepository userRoleRepository;

@Transactional
public void deleteUser(Long id) {
    // 删除用户角色关联
    userRoleRepository.deleteByUserId(id);
    
    // 删除用户
    userRepository.deleteById(id);
}
```

## 注意事项

1. **用户删除限制**: 系统管理员用户不应该被删除：

```java
@Transactional
public void deleteUser(Long id) {
    User user = userRepository.findById(id)
        .orElseThrow(() -> new BusinessException("用户不存在"));
    
    // 检查是否是管理员
    if ("admin".equals(user.getUsername())) {
        throw new BusinessException("系统管理员不能删除");
    }
    
    // 检查是否有创建的案件
    boolean hasCases = bankruptCaseRepository.existsByCreateUserId(id);
    if (hasCases) {
        throw new BusinessException("该用户创建了案件，不能删除");
    }
    
    // 删除关联
    userRoleRepository.deleteByUserId(id);
    
    // 删除用户
    userRepository.deleteById(id);
}
```

1. **角色删除限制**: 系统内置角色不应该被删除：

```java
@Transactional
public void deleteRole(Long id) {
    Role role = roleRepository.findById(id)
        .orElseThrow(() -> new BusinessException("角色不存在"));
    
    // 检查是否是系统角色
    if ("ADMIN".equals(role.getRoleCode()) || "USER".equals(role.getRoleCode())) {
        throw new BusinessException("系统内置角色不能删除");
    }
    
    // 删除关联
    userRoleRepository.deleteByRoleId(id);
    rolePermissionRepository.deleteByRoleId(id);
    
    // 删除角色
    roleRepository.deleteById(id);
}
```

1. **权限删除**: 权限通常是系统预定义的，不建议删除。如果必须删除，需要检查是否有角色在使用：

```java
@Transactional
public void deletePermission(Long id) {
    // 检查是否有角色在使用
    boolean inUse = rolePermissionRepository.existsByPermissionId(id);
    if (inUse) {
        throw new BusinessException("该权限正在被角色使用，不能删除");
    }
    
    permissionRepository.deleteById(id);
}
```
