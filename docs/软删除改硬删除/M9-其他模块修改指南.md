## 特殊说明

### 审计日志 (AuditLog)

审计日志是重要的安全审计数据，通常不应该被删除。建议：
1. 保留审计日志的软删除，或
2. 禁止删除审计日志，只允许查询
3. 如果需要清理，使用定时任务归档到历史表

```java
// 建议：禁止删除审计日志
@Transactional
public void deleteAuditLog(Long id) {
    throw new BusinessException("审计日志不允许删除");
}
```

### 聊天记录 (ChatMessage)

聊天记录可能涉及法律证据，删除需谨慎：
```java
// 建议：添加删除权限检查
@Transactional
public void deleteChatMessage(Long id, Long userId) {
    ChatMessage message = chatMessageRepository.findById(id)
        .orElseThrow(() -> new BusinessException("消息不存在"));
    
    // 只能删除自己的消息
    if (!message.getSenderId().equals(userId)) {
        throw new BusinessException("只能删除自己的消息");
    }
    
    chatMessageRepository.delete(message);
}
```

### 归档记录 (ArchiveRecord)

归档记录与案件紧密关联，案件删除时应级联删除：
```java
// 在 ArchiveRecordRepository 中
@Modifying
@Query("DELETE FROM ArchiveRecord r WHERE r.caseId = :caseId")
void deleteByCaseId(@Param("caseId") Long caseId);
```

### Token 和 SmsCode

这些通常是临时数据，有过期时间，不需要软删除：
- Token：有过期时间，过期后自动失效
- SmsCode：有过期时间，验证后自动失效

可以直接使用硬删除或定时清理。
