## 代码审查清单

### Repository 层审查

- [ ] 所有 `@Query` 注解中的 `isDeleted = false` 条件已删除
- [ ] 删除方法使用 `DELETE FROM` 而不是 `UPDATE ... SET isDeleted = true`
- [ ] 方法命名符合 JPA 规范（如 `findByCaseId` 而不是 `findByCaseIdAndIsDeletedFalse`）
- [ ] 级联删除方法已正确实现

**示例审查**：
```java
// ✅ 正确
@Query("SELECT c FROM BankruptCase c WHERE c.caseNumber = :caseNumber")
Optional<BankruptCase> findByCaseNumber(@Param("caseNumber") String caseNumber);

@Modifying
@Query("DELETE FROM CaseTask c WHERE c.caseId = :caseId")
void deleteByCaseId(@Param("caseId") Long caseId);

// ❌ 错误
@Query("SELECT c FROM BankruptCase c WHERE c.isDeleted = false AND c.caseNumber = :caseNumber")
Optional<BankruptCase> findByCaseNumber(@Param("caseNumber") String caseNumber);

@Modifying
@Query("UPDATE CaseTask c SET c.isDeleted = true WHERE c.caseId = :caseId")
void deleteByCaseId(@Param("caseId") Long caseId);
```

### Service 层审查

- [ ] 删除方法使用 `repository.delete()` 或 `repository.deleteById()`
- [ ] 没有 `setIsDeleted(true)` 的代码
- [ ] 级联删除顺序正确（先子表后父表）
- [ ] 事务注解 `@Transactional` 已添加
- [ ] 必要的业务校验已添加（如审批状态检查）

**示例审查**：
```java
// ✅ 正确
@Transactional
public void deleteBankruptCase(Long id) {
    // 先删除关联数据
    caseTaskRepository.deleteByCaseId(id);
    // ... 其他关联数据
    
    // 再删除主数据
    bankruptCaseRepository.deleteById(id);
}

// ❌ 错误
public void deleteBankruptCase(Long id) {
    BankruptCase case = bankruptCaseRepository.findById(id).orElseThrow();
    case.setIsDeleted(true);  // 软删除
    bankruptCaseRepository.save(case);
}
```

### 级联删除审查

- [ ] 删除父实体时，关联的子实体也被删除
- [ ] 删除顺序正确，避免外键约束错误

**级联删除顺序示例**：
```java
// ✅ 正确顺序
@Transactional
public void deleteWorkTeam(Long id) {
    // 1. 删除权限（最子级）
    permissionRepository.deleteByTeamMemberId(memberId);
    
    // 2. 删除成员
    memberRepository.deleteByTeamId(id);
    
    // 3. 删除团队（最父级）
    workTeamRepository.deleteById(id);
}
```

### 业务逻辑审查

- [ ] 删除前是否进行了必要的业务校验
- [ ] 是否有不能删除的数据（如已审批、已确认的数据）
- [ ] 错误提示信息是否清晰

**示例审查**：
```java
// ✅ 正确
@Transactional
public void deleteClaimConfirmation(Long id) {
    ClaimConfirmation confirmation = claimConfirmationRepository.findById(id)
        .orElseThrow(() -> new BusinessException("债权确认不存在"));
    
    // 业务校验
    if ("CONFIRMED".equals(confirmation.getStatus())) {
        throw new BusinessException("已确认的债权不能删除");
    }
    
    claimConfirmationRepository.delete(confirmation);
}
```

## 常见问题处理

### 问题1：删除时外键约束错误

**原因**：删除父表数据时，子表还有关联数据。

**解决**：确保先删除子表数据。

```java
// 错误
@Transactional
public void deleteFundAccount(Long id) {
    fundAccountRepository.deleteById(id);  // 外键约束错误
}

// 正确
@Transactional
public void deleteFundAccount(Long id) {
    // 先删除子表
    fundFlowRepository.deleteByAccountId(id);
    // 再删除父表
    fundAccountRepository.deleteById(id);
}
```

### 问题2：删除后查询还显示数据

**原因**：可能是缓存或查询条件未修改。

**解决**：
1. 检查 Repository 查询方法是否还包含 `isDeleted = false`
2. 清除 Hibernate 二级缓存
3. 确认使用的是硬删除而不是软删除

### 问题3：事务回滚不生效

**原因**：异常被捕获或未抛出 RuntimeException。

**解决**：
```java
// 错误
@Transactional
public void deleteCase(Long id) {
    try {
        bankruptCaseRepository.deleteById(id);
    } catch (Exception e) {
        log.error("删除失败", e);  // 异常被捕获，事务不会回滚
    }
}

// 正确
@Transactional(rollbackFor = Exception.class)
public void deleteCase(Long id) {
    bankruptCaseRepository.deleteById(id);
}
```
