# M2 - 债权模块修改指南

## 模块说明

债权模块管理破产案件中的债权人信息、债权申报、债权审核和债权确认等数据。

**开发优先级**：⭐⭐⭐⭐⭐ (高)

#### 1.1 CreditorClaimRepository

**文件**: `repository/CreditorClaimRepository.java`

**修改内容**:

```java
// 修改前
@Query("SELECT c FROM CreditorClaim c WHERE c.isDeleted = false AND c.caseId = :caseId")

// 修改后
@Query("SELECT c FROM CreditorClaim c WHERE c.caseId = :caseId")

// 或者使用JPA默认方法
Page<CreditorClaim> findByCaseId(Long caseId, Pageable pageable);
```

**删除方法修改**:
```java
// 修改前（如果是软删除）
@Modifying
@Query("UPDATE CreditorClaim c SET c.isDeleted = true WHERE c.caseId = :caseId")

// 修改后（硬删除）
@Modifying
@Query("DELETE FROM CreditorClaim c WHERE c.caseId = :caseId")

void deleteByCaseId(Long caseId);
```

### 步骤2：修改 Service

#### 2.1 CreditorClaimServiceImpl

**文件**: `service/impl/CreditorClaimServiceImpl.java`

**查找软删除逻辑**:
```java
// 修改前
public void deleteCreditorClaim(Long id) {
    CreditorClaim claim = creditorClaimRepository.findById(id)
        .orElseThrow(() -> new BusinessException("债权不存在"));
    claim.setIsDeleted(true);
    creditorClaimRepository.save(claim);
}

// 修改后
public void deleteCreditorClaim(Long id) {
    creditorClaimRepository.deleteById(id);
}
```

#### 2.2 批量删除方法

如果有批量删除方法：
```java
// 修改前
@Transactional
public void deleteByCaseId(Long caseId) {
    List<CreditorClaim> claims = creditorClaimRepository.findByCaseId(caseId);
    for (CreditorClaim claim : claims) {
        claim.setIsDeleted(true);
        creditorClaimRepository.save(claim);
    }
}

// 修改后
@Transactional
public void deleteByCaseId(Long caseId) {
    creditorClaimRepository.deleteByCaseId(caseId);
}
```

## 常见问题

### Q1: 债权申报和审核的关联关系如何处理？
**A**: 保持现有逻辑不变，只是将软删除改为硬删除。如果申报被删除，关联的审核记录也应该被级联删除。

### Q2: 债权确认数据是否可以删除？
**A**: 根据业务需求，已确认的债权可能不应该被删除。需要在Service层添加业务校验：
```java
public void deleteClaimConfirmation(Long id) {
    ClaimConfirmation confirmation = claimConfirmationRepository.findById(id)
        .orElseThrow(() -> new BusinessException("债权确认不存在"));
    
    // 如果已确认，不允许删除
    if ("CONFIRMED".equals(confirmation.getStatus())) {
        throw new BusinessException("已确认的债权不能删除");
    }
    
    claimConfirmationRepository.delete(confirmation);
}
```
