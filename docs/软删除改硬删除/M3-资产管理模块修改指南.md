## 详细修改步骤

### 步骤1：修改 Repository

#### 1.1 BankAccountRepository

**文件**: `repository/BankAccountRepository.java`

**修改内容**:
```java
// 修改前
@Query("SELECT b FROM BankAccount b WHERE b.isDeleted = false AND b.caseId = :caseId")
Page<BankAccount> findByCaseId(@Param("caseId") Long caseId, Pageable pageable);

// 修改后
Page<BankAccount> findByCaseId(Long caseId, Pageable pageable);
```

**删除方法**:
```java
// 修改前（软删除）
@Modifying
@Query("UPDATE BankAccount b SET b.isDeleted = true WHERE b.caseId = :caseId")
void deleteByCaseId(@Param("caseId") Long caseId);

// 修改后（硬删除）
@Modifying
@Query("DELETE FROM BankAccount b WHERE b.caseId = :caseId")
void deleteByCaseId(@Param("caseId") Long caseId);
```

#### 1.2 BankAccountTransactionRepository

**文件**: `repository/BankAccountTransactionRepository.java`

**特别注意**: 交易记录通常通过 `accountId` 关联，删除银行账户时需要级联删除交易记录。

```java
// 添加级联删除方法
@Modifying
@Query("DELETE FROM BankAccountTransaction t WHERE t.accountId = :accountId")
void deleteByAccountId(@Param("accountId") Long accountId);
```

#### 1.3 DebtorEnterpriseRepository

**文件**: `repository/DebtorEnterpriseRepository.java`

**修改内容**: 同上，删除 `isDeleted = false` 条件，修改 `deleteByCaseId` 为硬删除。

### 步骤2：修改 Service

#### 2.1 BankAccountServiceImpl

**文件**: `service/impl/BankAccountServiceImpl.java`

**删除银行账户时级联删除交易记录**:
```java
// 修改前
@Transactional
public void deleteBankAccount(Long id) {
    BankAccount account = bankAccountRepository.findById(id)
        .orElseThrow(() -> new BusinessException("银行账户不存在"));
    account.setIsDeleted(true);
    bankAccountRepository.save(account);
}

// 修改后
@Autowired
private BankAccountTransactionRepository transactionRepository;

@Transactional
public void deleteBankAccount(Long id) {
    // 先删除关联的交易记录
    transactionRepository.deleteByAccountId(id);
    
    // 再删除银行账户
    bankAccountRepository.deleteById(id);
}
```

## 级联删除注意事项

银行账户和交易记录存在一对多关系，删除时需要注意顺序：

1. 先删除交易记录（子表）
2. 再删除银行账户（父表）

如果数据库设置了外键级联删除，可以直接删除父表数据。
