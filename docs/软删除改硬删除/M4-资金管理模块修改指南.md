#### 1.1 FundAccountRepository

**修改内容**:

```java
// 修改后
List<FundAccount> findByCaseId(Long caseId);
```

**删除方法**:
```java
// 修改前
@Modifying
```

### 步骤2：修改 Service

#### 2.1 FundAccountServiceImpl

**文件**: `service/impl/FundAccountServiceImpl.java`

**修改删除逻辑**:
```java
// 修改前
@Transactional
public void deleteFundAccount(Long id) {
    FundAccount account = fundAccountRepository.findById(id)
        .orElseThrow(() -> new BusinessException("资金账户不存在"));
    account.setIsDeleted(true);
    fundAccountRepository.save(account);
}

// 修改后
@Autowired
private FundFlowRepository fundFlowRepository;

@Transactional
public void deleteFundAccount(Long id) {
    // 先删除关联的资金流水
    fundFlowRepository.deleteByAccountId(id);
    
    // 再删除资金账户
    fundAccountRepository.deleteById(id);
}
```

#### 2.2 ExpenseReimbursementServiceImpl

**文件**: `service/impl/ExpenseReimbursementServiceImpl.java`

**级联删除报销明细**:

## 注意事项

1. **资金流水不可恢复**: 资金流水是重要的审计数据，硬删除后无法恢复，请确保备份机制完善。

2. **审批状态检查**: 删除资金相关数据前，建议检查审批状态：
```java
@Transactional
public void deleteFundApproval(Long id) {
    FundApproval approval = fundApprovalRepository.findById(id)
        .orElseThrow(() -> new BusinessException("审批记录不存在"));
    
    // 如果已审批，不允许删除
    if ("APPROVED".equals(approval.getStatus())) {
        throw new BusinessException("已审批的记录不能删除");
    }
    
    fundApprovalRepository.delete(approval);
}
```

3. **事务一致性**: 确保所有级联删除操作在同一个事务中：
```java
@Transactional(rollbackFor = Exception.class)
public void deleteFundAccount(Long id) {
    // 所有操作在同一个事务中
    fundFlowRepository.deleteByAccountId(id);
    fundAccountRepository.deleteById(id);
}
```
