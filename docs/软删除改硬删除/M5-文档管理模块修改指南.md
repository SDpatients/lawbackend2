// 修改前
@Transactional
public void deleteDocument(Long id) {
    LibDocument document = libDocumentRepository.findById(id)
        .orElseThrow(() -> new BusinessException("文档不存在"));
    document.setIsDeleted(true);
    libDocumentRepository.save(document);
}

// 修改后
@Autowired
private LibDocumentVersionRepository versionRepository;
@Autowired
private LibDocumentShareRepository shareRepository;
@Autowired
private LibDocumentFavoriteRepository favoriteRepository;

public void deleteDocument(Long id) {
    // 删除关联的版本记录
    versionRepository.deleteByDocumentId(id);
    
    // 删除分享记录
    shareRepository.deleteByDocumentId(id);
    
    // 删除收藏记录
    favoriteRepository.deleteByDocumentId(id);
    
    // 删除文档

}

#### 2.2 LibDocumentFolderServiceImpl

**文件**: `service/impl/LibDocumentFolderServiceImpl.java`

**递归删除文件夹及其内容**:
```java
// 修改前
@Transactional
public void deleteFolder(Long id) {
    LibDocumentFolder folder = libDocumentFolderRepository.findById(id)
        .orElseThrow(() -> new BusinessException("文件夹不存在"));
    folder.setIsDeleted(true);
    libDocumentFolderRepository.save(folder);
}

// 修改后
@Autowired
private LibDocumentRepository documentRepository;
@Autowired
private LibFolderPermissionRepository permissionRepository;

@Transactional
public void deleteFolder(Long id) {
    // 递归删除子文件夹
    deleteSubFolders(id);
    
    // 删除文件夹内的所有文档
    documentRepository.deleteByFolderId(id);
    
    // 删除文件夹权限
    permissionRepository.deleteByFolderId(id);
    
    // 删除文件夹
    libDocumentFolderRepository.deleteById(id);
}

private void deleteSubFolders(Long parentId) {
    List<LibDocumentFolder> subFolders = libDocumentFolderRepository.findByParentId(parentId);
    for (LibDocumentFolder folder : subFolders) {
        deleteSubFolders(folder.getId());
        documentRepository.deleteByFolderId(folder.getId());
        permissionRepository.deleteByFolderId(folder.getId());
        libDocumentFolderRepository.deleteById(folder.getId());
    }
}
```

## 注意事项

1. **文件夹递归删除**: 删除文件夹时需要递归删除所有子文件夹和内容。

2. **物理文件删除**: 如果文档有物理文件存储，需要在删除数据库记录后删除物理文件：
```java
@Transactional
public void deleteDocument(Long id) {
    LibDocument document = libDocumentRepository.findById(id)
        .orElseThrow(() -> new BusinessException("文档不存在"));
    
    // 删除物理文件
    String filePath = document.getFilePath();
    if (filePath != null) {
        fileStorageService.delete(filePath);
    }
    
    // 删除数据库记录
    versionRepository.deleteByDocumentId(id);
    shareRepository.deleteByDocumentId(id);
    libDocumentRepository.deleteById(id);
}
```

3. **分享链接失效**: 文档删除后，分享链接应该失效。由于采用硬删除，分享记录也会被删除，链接自然失效。
