### 步骤2：修改 Service

#### 2.1 WorkTeamServiceImpl

**文件**: `service/impl/WorkTeamServiceImpl.java`

**级联删除团队及其成员和权限**:
```java
// 修改前
@Transactional
public void deleteWorkTeam(Long id) {
    WorkTeam team = workTeamRepository.findById(id)
        .orElseThrow(() -> new BusinessException("工作团队不存在"));
    team.setIsDeleted(true);
    workTeamRepository.save(team);
}

// 修改后
@Autowired
private WorkTeamMemberRepository memberRepository;
@Autowired
private WorkTeamPermissionRepository permissionRepository;

@Transactional
public void deleteWorkTeam(Long id) {
    // 获取团队成员
    List<WorkTeamMember> members = memberRepository.findByTeamId(id);
    
    // 删除成员权限
    for (WorkTeamMember member : members) {
        permissionRepository.deleteByTeamMemberId(member.getId());
    }
    
    // 删除团队成员
    memberRepository.deleteByTeamId(id);
    
    // 删除工作团队
    workTeamRepository.deleteById(id);
}
```

## 注意事项

1. **权限删除顺序**: 必须先删除权限，再删除成员，最后删除团队。

2. **案件删除时的顺序**: M1模块已经按正确顺序调用删除方法：
```java
// 先删除权限
workTeamPermissionRepository.deleteByCaseId(caseId);
// 再删除成员
workTeamMemberRepository.deleteByCaseId(caseId);
// 最后删除团队
workTeamRepository.deleteByCaseId(caseId);
```

3. **团队成员业务校验**: 删除团队成员前，可以检查是否有进行中的任务：
```java
@Transactional
public void deleteWorkTeamMember(Long memberId) {
    // 检查是否有进行中的任务
    boolean hasActiveTasks = taskRepository.existsByAssigneeIdAndStatus(memberId, "IN_PROGRESS");
    if (hasActiveTasks) {
        throw new BusinessException("该成员有进行中的任务，不能删除");
    }
    
    // 删除权限
    permissionRepository.deleteByTeamMemberId(memberId);
    
    // 删除成员
    memberRepository.deleteById(memberId);
}
```
