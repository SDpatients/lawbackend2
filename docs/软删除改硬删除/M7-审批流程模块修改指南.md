### 步骤2：修改 Service

#### 2.1 ApprovalServiceImpl

**文件**: `service/impl/ApprovalServiceImpl.java`

**级联删除审批及其历史**:
```java
// 修改前
@Transactional
public void deleteApproval(Long id) {
    Approval approval = approvalRepository.findById(id)
        .orElseThrow(() -> new BusinessException("审批记录不存在"));
    approval.setIsDeleted(true);
    approvalRepository.save(approval);
}

// 修改后
@Autowired
private ApprovalHistoryRepository historyRepository;

@Transactional
public void deleteApproval(Long id) {
    // 删除审批历史
    historyRepository.deleteByApprovalId(id);
    
    // 删除审批记录
    approvalRepository.deleteById(id);
}
```

## 注意事项

1. **审批历史的重要性**: 审批历史是审计追踪的重要数据，硬删除后将无法恢复。请确保备份机制完善。

2. **审批状态检查**: 删除审批记录前，建议检查审批状态：
```java
@Transactional
public void deleteApproval(Long id) {
    Approval approval = approvalRepository.findById(id)
        .orElseThrow(() -> new BusinessException("审批记录不存在"));
    
    // 如果审批已完成，不允许删除
    if ("COMPLETED".equals(approval.getStatus())) {
        throw new BusinessException("已完成的审批不能删除");
    }
    
    // 删除历史
    historyRepository.deleteByApprovalId(id);
    
    // 删除审批
    approvalRepository.delete(approval);
}
```

3. **管理人关联检查**: 删除管理人前，检查是否有关联的案件：
```java
@Transactional
public void deleteAdministrator(Long id) {
    Administrator admin = administratorRepository.findById(id)
        .orElseThrow(() -> new BusinessException("管理人不存在"));
    
    // 检查是否有关联的进行中的案件
    boolean hasActiveCases = bankruptCaseRepository.existsByAdministratorIdAndStatus(id, "ONGOING");
    if (hasActiveCases) {
        throw new BusinessException("该管理人有进行中的案件，不能删除");
    }
    
    administratorRepository.delete(admin);
}
```
