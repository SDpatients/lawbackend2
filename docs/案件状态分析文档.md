## 三、已报结案件的判断

### 3.1 如何判断案件已报结

**判断条件**：`case_status = 'AWAITING'`

```java
// 判断案件是否已报结
public boolean isCaseAwaiting(BankruptCase case) {
    return "AWAITING".equals(case.getCaseStatus());
}
```

### 3.2 报结状态的触发条件

案件进入"报结"状态（AWAITING）的触发条件：

**代码位置**：[ApprovalServiceImpl.java](file:///d:/Ai/lawbackend2/src/main/java/com/lawbackend2/lawbackend2/service/impl/ApprovalServiceImpl.java#L119-L125)

```java
if ("CASE_SUBMIT".equals(request.getApprovalType())) {
    // 案件提交报结申请
    // 将案件状态改为 AWAITING
    bankruptCase.setCaseStatus("AWAITING");
    bankruptCaseRepository.save(bankruptCase);
}
```

**触发流程**：
1. 用户提交案件报结申请（`approvalType = "CASE_SUBMIT"`）
2. 系统将案件状态改为 `AWAITING`（报结）
3. 等待管理员审核确认

## 四、已报结案件与进行中案件的区别

### 4.1 功能权限区别

| 功能 | 进行中案件 | 已报结案件（AWAITING） |
|------|-----------|----------------------|
| 编辑案件基本信息 | ✓ | ✗ |
| 添加/编辑任务 | ✓ | ✗ |
| 提交任务 | ✓ | ✗ |
| 债权申报 | ✓ | ✗ |
| 债权人会议 | ✓ | ✗ |
| 财产分配 | ✓ | ✗ |
| 费用报销 | ✓ | ✗ |
| 公告发布 | ✓ | ✗ |
| 查看案件详情 | ✓ | ✓ |
| 查看历史记录 | ✓ | ✓ |
| 下载附件 | ✓ | ✓ |

### 4.2 数据统计区别

**代码位置**：[BankruptCaseServiceImpl.java](file:///d:/Ai/lawbackend2/src/main/java/com/lawbackend2/lawbackend2/service/impl/BankruptCaseServiceImpl.java#L758-L776)

```java
// 进行中的状态
if ("PENDING".equals(status) || "ONGOING".equals(status) || "APPROVED".equals(status)) {
    inProgressCount += count;
}

// 已结案的状态
if ("COMPLETED".equals(status)) {
    completedCount += count;
}
```

**统计分类**：

| 统计类型 | 包含状态 |
|----------|----------|
| 进行中案件 | PENDING, ONGOING, IN_PROGRESS, APPROVED |
| 已报结案件 | AWAITING |
| 已结案案件 | COMPLETED, CLOSED, TERMINATED, ARCHIVED |

### 4.3 业务流程区别

```
【进行中案件】
├── 可以执行所有业务操作
├── 任务可以提交、审核
├── 资金可以划转、报销
├── 公告可以发布
└── 债权人会议可以召开

【已报结案件（AWAITING）】
├── 业务操作受限
├── 等待管理员最终审核
├── 审核通过 → 状态变为 COMPLETED/CLOSED
└── 审核拒绝 → 状态回退到 ONGOING
```

## 六、相关API接口

### 6.1 更新案件状态

**接口地址**：`PUT /bankrupt-case/{caseId}/status`

**请求参数**：
```json
{
    "caseStatus": "AWAITING",
    "remark": "提交报结申请"
}
```

### 6.2 查询案件列表（按状态筛选）

**接口地址**：`GET /bankrupt-case/list?caseStatus=AWAITING`

### 6.3 提交案件报结申请

**接口地址**：`POST /approval`

**请求参数**：
```json
{
    "caseId": 1,
    "approvalType": "CASE_SUBMIT",
    "approvalTitle": "案件报结申请",
    "approvalContent": "申请报结原因说明"
}
```

## 七、前端判断示例

### 7.1 判断案件是否已报结

```javascript
// 判断案件是否已报结
function isCaseAwaiting(caseStatus) {
    return caseStatus === 'AWAITING';
}

// 判断案件是否可编辑
function canEditCase(caseStatus) {
    const editableStatus = ['PENDING', 'ONGOING', 'IN_PROGRESS', 'APPROVED'];
    return editableStatus.includes(caseStatus);
}

// 判断案件是否已结束
function isCaseFinished(caseStatus) {
    const finishedStatus = ['COMPLETED', 'CLOSED', 'TERMINATED', 'ARCHIVED'];
    return finishedStatus.includes(caseStatus);
}
```

## 八、注意事项

1. **状态一致性**：案件状态变更应通过API接口进行，避免直接修改数据库

2. **权限控制**：已报结案件（AWAITING）的业务操作需要在前端进行限制

3. **状态回退**：报结申请被拒绝后，案件状态会回退到 ONGOING

4. **统计口径**：进行中案件统计不包含 AWAITING 状态

5. **归档流程**：案件归档前需要确保所有相关数据已完成处理
