# 1月21日案件流程后端设计文档

## 1. 概述

本文档描述破产案件流程管理模块的后端设计方案，该模块主要用于管理人和负责人视角的案件流程处理和文件上传功能。系统采用方案B：创建独立的CaseTask表来管理23个核心任务。

## 2. 设计目标

- 提供案件全流程的文件集中管理功能
- 支持管理人对案件任务的文件上传和管理
- 自动为每个案件创建23个标准核心任务
- 简化任务管理，仅关注状态和文件，不涉及复杂的时间进度管理
- 确保数据权限控制，管理人只能操作自己负责的案件任务

## 3. 核心功能模块

### 3.1 案件任务管理模块（CaseTask）

#### 3.1.1 功能描述

管理案件全流程的23个核心任务，每个任务包含：
- 任务基本信息（任务名称、描述、状态）
- 任务关联的文件列表
- 任务所属的案件信息

#### 3.1.2 任务状态定义

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| IN_PROGRESS | 进行中 | 任务正在进行，默认状态 |
| COMPLETED | 已完成 | 任务已完成 |
| REVIEWING | 核审中 | 任务正在审核 |
| SKIPPED | 跳过 | 任务被跳过 |
| REJECTED | 被驳回 | 任务被驳回 |

## 7. 业务逻辑实现

### 7.1 案件创建时自动生成23个任务

在BankruptCaseService的createCase方法中，调用CaseTaskService的createTasksForCase方法：

```java
@Service
public class BankruptCaseServiceImpl implements BankruptCaseService {
    
    @Autowired
    private CaseTaskService caseTaskService;
    
    @Override
    @Transactional
    public BankruptCase createCase(CaseCreateRequest request, Long userId) {
        BankruptCase bankruptCase = new BankruptCase();
        bankruptCase.setCaseNumber(request.getCaseNumber());
        bankruptCase.setCaseName(request.getCaseName());
        bankruptCase.setCreatorName(request.getCreatorName());
        bankruptCase.setCreateUserId(userId);
        
        BankruptCase savedCase = bankruptCaseRepository.save(bankruptCase);
        
        caseTaskService.createTasksForCase(savedCase.getId());
        
        return savedCase;
    }
}
```

### 7.3 权限控制

确保管理人只能操作自己负责的案件任务，通过DataPermissionAspect实现：

```java
@Aspect
@Component
public class DataPermissionAspect {
    
    @Autowired
    private WorkTeamService workTeamService;
    
    @Before("@annotation(dataPermission)")
    public void checkDataPermission(JoinPoint joinPoint, DataPermission dataPermission) {
        Long userId = SecurityUtil.getCurrentUserId();
        Long caseId = extractCaseId(joinPoint);
        
        boolean hasPermission = workTeamService.hasCaseAccess(userId, caseId);
        if (!hasPermission) {
            throw new PermissionDeniedException("无权访问该案件数据");
        }
    }
}
```
